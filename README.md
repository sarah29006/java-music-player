# java-music-player
A simple command-line music player built using Java and the Java Sound API.

## Features

* Play audio
* Stop audio
* Reset the song to the beginning
* Quit the music player
* User input through the console

## Technologies Used

* Java
* Java Sound API
* 'AudioInputStream'
* 'Clip'
* 'Scanner'

## Supported Audio Files

This project uses Java's Sound API and supports audio formats such as:

* WAV
* AU
* AIFF

## How to Run

1. Clone or download this repository.
2. Open the project in a Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.
3. Add a supported '.wav', '.au', or '.aiff' audio file to the project.
4. Update the 'filePath' in 'Main.java' to the location of your audio file.
5. Run 'Main.java'.

## Controls

| Key | Action |
| --- | ------ |
| P   | Play   |
| S   | Stop   |
| R   | Reset  |
| Q   | Quit   |
